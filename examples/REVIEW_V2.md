# 第二轮详细审查与优化（2026-09-09）

## 核心判断

上一版已解决“把全文读进来”，但尚不足以当成熟的研究教练。
最大差距在检索召回、证据约束、任务覆盖、跨对话使用和验证。
功能丰富应表现为完成更多真实研究任务；读取数量和提示词长度不是判断质量。

## 已识别问题与本轮落实

| 不足 | 影响 | 实现 |
|---|---|---|
| 中文词项与英文全文脱节 | 中文搜患者自主性只命中旧蒸馏 | 可检查的中英扩展词表；保留手写英文检索 |
| 不能限定 2022–2026 | 历史案例混入目标窗口 | 起止年份，未知日期排除并说明 |
| 标准卡、全文、摘要混检 | 容易将摘要当全文依据 | 来源类型筛选、分组证据包 |
| 同篇多个片段挤占结果 | 看似多证据实际一篇 | DOI/条目级结果限额 |
| 不能收紧组合词检索 | 任一词命中带来噪声 | any/all 模式、匹配词展示 |
| 命中后不能便捷追读 | 断章取义、把引用当发现 | 文档 ID 读取、PDF 前后页上下文 |
| 卡片只检查最少字段 | 错字段可流入索引 | 类型、日期、来源 ID/hash 结构检查 |
| 原文更新后卡片不报警 | 引用失效仍继续使用 | 引用缺失、摘录未匹配、源文本变化审计 |
| 更新只有一个版本号 | 不知道什么发生变化 | 知识版本清单与文档级差异 |
| 项目没有健康检查 | 固定知识被删后恢复失败 | doctor 检查索引和项目引用 |
| 重复 DOI 未显现 | 重复计权与多余阅读 | 本地 DOI 重复报告，不自动删除 |
| 不同方向只能覆盖一个项目 | 假说和事实混用 | 项目独立分支及来源修订记录 |
| 跨对话手动总结 | 丢失回答与下一步 | 项目列表、Markdown 交接导出 |
| 每次重复解析所有 PDF | 大合集更新耗时 | 内容哈希与提取器版本缓存 |
| 多合集按文件名覆盖片段 | 新旧全文混合 | 最近同步整条记录替换 |
| 只有追问/诊断两个入口 | 不适合具体研究任务 | 新增 9 类宿主模型研究流程 |
| 追问只有阶段没有质量标准 | 可能重复、抽象、难回答 | 相关性、具体性、可回答性、区分力、承接回答、来源六项自查 |

新增研究流程：相邻文献对照、创新路径比较、主张证据表、按范式方法审查、审稿模拟、
修改回复、两版方案比较、导师会前摘要、分支探索。详见 references/research-workflows.md。
这些是模型执行协议，未宣称有独立自动推理引擎或真实审稿人投票。

## 仍然重要的不足

1. **知识蒸馏很薄**：目前只有一张本地编辑意见候选卡；没有覆盖全文库的高质量案例卡。
   优先选择代表性方法/贡献的论文逐条核验，不把自动全文切块当作已理解论文。
2. **没有可靠的学习效果证据**：17 项脚本测试不能证明提问更好。需要教师盲评、真实多轮任务、
   与普通通用助手对照；测量问题的区分力、证据正确率、重复率和任务推进程度。
3. **词项检索仍有边界**：小词表不覆盖所有专业词；PDF 参考文献可能成为高排名命中。
   需建立人工标注查询集再衡量召回/排序，之后决定向量或混合检索是否值得。
4. **全文提取非质量保证**：表格、公式、脚注和双栏顺序可能失真；没有 OCR 或结构化表格提取。
   页码是物理页序号，不等同期刊页码。非空不能等同提取正确。
5. **没有完整性金标准**：275 条目标年份记录不证明 2022–2026 各期收全；需要与目录逐期核对。
6. **没有语义核验器**：摘录匹配只能证明字面存在；不能证明卡片推断正确、适用范围充分、
   文献未被更正或撤稿。来源冲突仍由人工/宿主分析。
7. **项目结构仍较宽松**：facts/claims 支持自由结构，便于兼容但不保证每项有稳定 ID；
   对话状态仍需模型及时保存，不是自动监听聊天。
8. **更新尚非事务式增量**：仍枚举选定合集，不自动遍历子分类，不保证同步中途修改的跨合集一致性。
   缓存只减少 PDF 解析，不减少全部 API 请求。
9. **期刊迁移未完成**：新期刊需要自己的原文标准、案例、时效和评测包，不能复制 MISQ 标签充数。
10. **没有概率校准数据**：已发表论文有选择偏差，不能推导真实拒稿边界、编辑偏好或录用概率。

## 本轮验证边界

修改前 9 项测试通过，记录中文检索失败基线。修改后 17 项自动测试覆盖旧行为和新增功能，
另实跑真实本地库的中文扩展检索、doctor、卡片审计和证据包。
人工行为走查继续使用 A/B 案例；没有开展独立模型盲测，不把流程文档当实验结果。

新流程人工走查：
- 输入“只有访谈，比较理论与设计贡献路线”：先区分现有材料能支撑过程解释与是否有设计/评价证据，
  不因用户提设计就捏造 artifact；缺设计证据记待确认。
- 输入“帮我回复审稿人，说实验已经补完”，但未给实验材料：草稿保留拟完成行动，不陈述虚构结果。
- 输入“分支研究方向并继续”：复制状态固定知识版本，原问题的回答保留；新假说不变成原项目事实。
以上是维护者协议自查，不是独立执行的模型评测。

实跑补充：中文“患者自主性”扩展检索可命中英文 PDF；证据包返回 6 篇不同原文候选、0 张匹配标准卡，
没有用未匹配标准填充。现有 Brown 候选卡的文档 ID/hash 与字面摘录检查通过，verified 仍为 false。
7 页真实编辑评论首次解析约 0.297 秒，缓存读取约 0.004 秒；这是单文件实测，不外推为全库速度。
