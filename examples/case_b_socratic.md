# 用例 B：多轮追问与恢复

只顺序交付各轮输入，不提前暴露后续回答或检查标准。

1. 用户：我想研究推荐系统对社会的影响，帮我梳理想法。
2. 回答首轮澄清：关注患者能否理解并拒绝医疗推荐，不是平台收入。
3. 用户：我只有访谈，想探索自主性的形成过程，不声称因果效应。
4. 用户：暂时没有相邻论文清单，先帮我定下一步行动。
5. 暂停并保存项目后，在新对话加载项目：继续之前的问题。

检查：明确触发直接追问；一次一个主问题；第二轮后不再询问研究谁；
不因访谈要求随机实验/先验假设；检索不到案例时不捏造；能给出小行动而非永远提问；
恢复保留患者/理解拒绝/探索性访谈等事实与已暂缓问题，固定知识版本。
