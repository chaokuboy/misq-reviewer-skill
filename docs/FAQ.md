# 常见问题

## 下载后是否已经读过五年 MISQ 全文？
没有。公开包有画像、历史蒸馏和工具，没有开发者全文库或私人知识卡。
你需接入自己的文献；提取出文本也不等于完成论文理解或人工核验。

## 没有 Zotero 或 Python 能用吗？
能。把必要 Markdown 文档交给模型即可进行静态追问与诊断。
不能使用的检索和保存功能应明确说明，不影响先讨论研究想法。

## 它会自动提问、生成创新点并给分吗？
宿主模型按 SKILL 追问和评价，脚本不独立运行研究对话。
可以比较贡献路径，但没有经过教师校准的自主评分器；不应将自评分解释为真实录用可能。

## 新聊天会记住旧项目吗？
不会自动记住。需提供项目导出摘要，或让模型读取本地项目状态及对应知识版本。
没有文件工具时请复制上轮交接摘要。分支复制的是记录，不是已经训练好的模型知识。

## 搜不到文献／标准卡，是不是研究有创新？
不是。先确认 build、资料范围、年份和来源类型筛选，再尝试英文同义词。
干净安装没有私人卡片，verified-only 或 packet 返回空可能正常。没有命中不能证明新颖性。

## Zotero 连接失败怎么办？
确认 Zotero 正在运行且允许本地 API；脚本从同一环境访问 127.0.0.1:23119。
远程容器、WSL 或其他机器的 localhost 不是你的桌面。不要将 Web API key 当作本地连接修复办法。
查看错误和 failures；失败不等于已更新。具体限制见本地工具文档。

## 索引不存在／SQLite 报 no such module: fts5？
索引不存在时先 build，并确保使用相同 --home。FTS5 错误需要带此扩展的 Python/SQLite 环境。
全局参数放在命令前，例如 `python3 tools/research_assistant.py --home /私有数据目录 build`。
默认 home 是脚本所在仓库的 .local，不随终端当前目录改变。

## PDF 有文字但提取失败，或表格乱码？
先确认附件路径、访问权限和 PDF 本身。后备提取用可选 pypdf；复杂版面可用质量工具看页图。
OCR、表格提取结果仍是候选，需要核对版面，不自动替换正文索引或生成可信公式。

## 来源标为 review_required 怎么办？
回查原文、卡片限定条件和出版通知，不能直接把该条用作已成立标准。
后续未查到通知不会自动解除旧警报；model_supported 不等于人工核验。

## 支持别的期刊、英文交流吗？
可以按用户语言交流，但现有知识档案面向 MISQ。其他刊会需要独立的来源和适用规则，
不能只换名称就宣称完成适配。

## 能复现所有历史评测吗？
离线软件测试可直接运行。历史模型运行还需要当时的模型、输入与上下文；部分原件在开发者本地，
公开报告不能替代原件。DeepSeek 导入工具需要外部材料包，不能在干净安装上凭空生成该数据。

## 数据是否只留在本机？
本地索引工具将资料保存在本机；宿主若是云端模型，读取的内容仍可能进入其服务。
不要把 .local、附件、凭据或私人稿件加入公开提交。MIT 不授权再次分发期刊全文。
