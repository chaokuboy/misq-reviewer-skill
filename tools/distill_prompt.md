# MISQ 画像凝练提示词

> 用途：把 `profiles/misq_recent5y.jsonl`（519 篇摘要）+ Editor's Comments 凝练成 `profiles/misq.md` 的画像内容。
> 建议分批喂（每批 50 篇摘要），最后合并。

---

## 使用方法（三步）

1. 让模型先读 `profiles/misq.md`（画像模板，含 7 个维度 + 填写位置）。
2. 把下面的提示词 + 一批摘要（每批约 50 条）发给模型，让它对**该批**做提炼。
3. 所有批跑完后，把各批结论合并，回填 `profiles/misq.md`；主观维度（贡献标准/拒稿理由/创新类型）优先用 Editor's Comments 校正。

---

## 可直接复制给模型的提示词

### System

```
你是一位深耕信息系统（IS）领域的资深期刊审稿人，曾为 MIS Quarterly（MISQ）审稿十余年，
对该刊的定位、审稿尺度、拒稿理由、理论贡献标准有极其敏锐的判断。

你的任务：根据我提供的 MISQ 近年论文摘要（和可选的 Editor's Comments），
提炼出一份「期刊审稿画像」，用于后续对我进行苏格拉底式追问——
让每一个追问都锚定在"MISQ 审稿人真正关心、决定能否发表"的问题上，而不是泛泛而谈。
```

### 提炼指令（每批都发）

```
请对下面这批 MISQ 论文摘要做凝练（不要罗列原文，要提炼成可操作的审稿标准）：

【提炼目标】按以下 7 个维度输出，每个维度给出"结论式"内容，禁止空话（如"要有贡献"）：

1. 选题边界：这批研究集中在哪些主题？哪些明显"不属于 MISQ 会收的题"？
2. 理论贡献句：摘要是如何表述"贡献"的？归纳出 MISQ 认可的高频贡献类型。
3. 方法偏好：统计方法关键词（实验/问卷/计量/质性/设计科学/机器学习/二手数据…），列出主流与边缘方法。
4. 拒稿信号：从摘要措辞中找"可能被审稿人挑刺"的点，每条配一句审稿人式的逼问。
5. 创新表述：这些研究如何描述自己的"新意"？区分高价值创新 vs 情境复制/模型微调。
6. 热点问题：这批摘要反复在回答什么研究问题？（给出主题聚类）
7. 关键概念：高频出现的构念/理论/术语清单。

【输出格式】严格按 profiles/misq.md 的维度结构输出 markdown，能填进模板。
【特别注意】如果同时给了 Editor's Comments，则维度 2/4/5 以 Editor's Comments 为准，摘要只作佐证。
```

### 附：Editor's Comments 专用提示词（editorial 单独喂一次）

```
下面是 MISQ 若干期 Editor's Comments（主编编者按）。这是提炼"审稿标准/拒稿理由/期刊价值观"的黄金材料，
请逐条提炼：
1. 主编明确说的"我们要什么 / 不要什么"。
2. 主编对"理论贡献""创新""方法严谨性"的具体要求原文摘句。
3. 主编提到的学科发展趋势判断。
输出为可操作的审稿标准清单，每条配一句可追问的话。
```

## 分批策略建议

| 批 | 内容 | 目的 |
|---|---|---|
| 1–11 | 519 篇摘要，每批约 50 篇 | 维度 1/3/6/7（边界、方法、热点、概念） |
| 12 | 全部 Editor's Comments | 维度 2/4/5（贡献标准、拒稿理由、创新类型） |
| 合并 | 汇总各批 + editorial 结论 | 回填 `profiles/misq.md` 最终版 |

> 实际喂给模型时，每批从 `misq_recent5y.jsonl` 取 50 行即可（字段：title + abstract + year）。
